# LRL_ODMParserFromVDV_App

## Purpose
Reads VDV Codelist Items Compare Tool output coversheet and processes corresponding archived DED xml file. Tool to aid STATS alignment with DED standards for studies processes by  VDV Codelist Items Compare Tool Output run by Study Build Team.
